Installation:
Go to your Interface/Addon folder for Ascension and add the files in a folder named "InstanceCounter" - you may also used the provided compressed file, dragging and dropping the folder into the Addon Folder.

How it works:
A simple addon that keeps track of any instances you have entered along with a timestamp : the fixed frame can be cursored over and provide a quick tooltip.  When you reach five instances, it will check the time compared to a global timer of 1 hour since initial instance entry.
This 1 hour timer is seperate and will tick down as you play, regardless of what tasks you do.  If you are at 5 instances and the timer is active, that timer will tell you how long it will take for your next instance to activate to avoid that annoying "You've entered too many instances!" dialouge.
